# Agentic Government — ورشة ذكاء اصطناعي لموظفي JEDCO

> **🇬🇧 [Read this file in English](README.md)**

ورشة عملية مدتها ساعتان تُعرّف موظفي [المؤسسة الأردنية لتطوير المشاريع الاقتصادية (JEDCO)](https://www.jedco.gov.jo) على استخدام أدوات الذكاء الاصطناعي في مهامهم اليومية — كتابة المستندات، مراجعة طلبات التمويل، وأتمتة المهام المتكررة. النظام يعمل محلياً، لا بيانات تغادر الجهاز.

## فكّر بالأمر هكذا

> كل الناس معها سيف — المهارة إنك تعرف تستخدمه:
>
> | الأداة | ماذا أتمت؟ | من يقرّر؟ |
> |--------|------------|----------|
> | **Excel** | الحسابات والجداول | **أنت** |
> | **الوكيل الذكي** | قراءة المستندات، كتابة الرسائل، مقارنة الطلبات | **أنت** |
>
> الموظف يبقى صاحب القرار. الأداة تتولى الجزء المتكرر حتى تتفرّغ لما يحتاج خبرتك.

## المؤسسة المستضيفة

**[المؤسسة الأردنية لتطوير المشاريع الاقتصادية (JEDCO)](https://www.jedco.gov.jo)** — تأسست ١٩٧٢، عمّان، الأردن

**برامج JEDCO المستخدمة في العروض:**

| البرنامج | الغرض |
|---------|-------|
| **تمكين** | بناء قدرات المنشآت الصغيرة والمتوسطة |
| **ابدأ مشروعك** | دعم إطلاق المشاريع الناشئة |
| **تطوير** | تطوير الأعمال والنمو |
| **حياة كريمة في البيت** | دعم المشاريع المنزلية |
| **صدّر منتجك** | تسهيل التصدير للمنشآت |
| **المعارض والبازارات** | الوصول للأسواق عبر المعارض التجارية |

**مهام الموظفين اليومية (التدريب مبني حولها):**
- مراجعة طلبات تمويل المنشآت والشركات الناشئة وتحديد الأهلية
- كتابة رسائل قرارات التمويل وتقارير البرامج (بالعربية)
- التنسيق مع الجهات المانحة والشركاء الدوليين
- إدارة برامج الإنتاجية والتوظيف الريفي

## هيكل التدريب

| # | البلوك | المدة | سياق JEDCO |
|---|--------|-------|-----------|
| ٠ | كيف يعمل الذكاء الاصطناعي (تشبيه الموظف الجديد) | ١٠ د | قرأ كل شيء، لم يُجرّب شيئاً |
| ١ | ما هو الوكيل الذكي؟ | ١٥ د | مفاهيم عامة، أمثلة حكومية |
| ٢ | عرض كتابة المستندات | ٢٥ د | كتابة رسالة قرار تمويل بالعربية |
| ٣ | عرض مراجعة الطلبات | ٢٥ د | مراجعة طلب تطوير/تمكين وهمي عبر AnythingLLM |
| ٤ | صيغة RCTF لكتابة الأوامر | ٢٠ د | أمثلة من برامج JEDCO |
| ٥ | عرض الوكيل الآلي | ٢٠ د | أتمتة مراحل معالجة الطلبات المتكررة |
| ٦ | الاستخدام الآمن + أسئلة وأجوبة | ١٥ د | حماية البيانات + مبادئ الذكاء الاصطناعي الحكومي |

## منظومة الأدوات (محلية / خاصة — لا سحابة، لا بيانات تغادر الجهاز)

| الأداة | الدور | لماذا؟ |
|--------|------|--------|
| **Ollama** | محرك نماذج محلي | لا مفتاح API، لا إنترنت مطلوب |
| **qwen3:8b** | النموذج اللغوي الرئيسي (٥.٢ جيجا) | أحدث Qwen3، عربي، تفكير، أدوات، يعمل على ٦ جيجا VRAM |
| **qwen2.5:7b** | نموذج احتياطي (٤.٧ جيجا) | مُجرّب، سريع، دعم عربي |
| **gemma3:4b-it-qat** | نموذج خفيف (٤.٠ جيجا) | دعم الصور، نافذة سياق ١٢٨ ألف |
| **gemma4:e4b** | تجريبي (٩.٦ جيجا) | نافذة سياق ١٢٨ ألف، تفكير، جزئي على ٦ جيجا |
| **AnythingLLM** | أسئلة وأجوبة المستندات | تحميل واستعلام مستندات JEDCO |
| **faster-whisper** | تحويل الكلام العربي لنص | `pip install faster-whisper`، يعمل على CUDA |

## مسار معالجة اللغة العربية

```
كلام عربي ← Whisper large-v3 (faster-whisper, CUDA) ← نص عربي ← qwen3:8b عبر Ollama ← المخرجات
```

## متطلبات الأجهزة

**الجهاز المستخدم في الورشة:** Intel i7-10750H · ١٦ جيجا ذاكرة · NVIDIA RTX 2060 — **٦ جيجا VRAM**

| النموذج | الحجم | يعمل على ٦ جيجا؟ | الحالة | الاستخدام |
|---------|-------|-----------------|--------|----------|
| `gemma3:4b-it-qat` | ٤.٠ جيجا | ✅ | مثبّت | عام، صور، نافذة سياق ١٢٨ ألف |
| `qwen2.5:7b` | ٤.٧ جيجا | ✅ | مثبّت | عربي، متعدد اللغات، سريع |
| `qwen3:8b` | ٥.٢ جيجا | ✅ | **مثبّت — الافتراضي** | أحدث Qwen3، تفكير، أدوات |
| `gemma4:e4b` | ٩.٦ جيجا | ⚠️ جزئي | مثبّت | نافذة سياق ١٢٨ ألف، يتجاوز للذاكرة |
| `qwen3:14b` | ٩.٣ جيجا | ❌ | — | كبير جداً لـ ٦ جيجا |

> شغّل نموذجاً واحداً في كل مرة. **`qwen3:8b` هو النموذج الموصى به** — تم اختباره والتحقق منه على هذا الجهاز مع مسار معالجة JEDCO.
