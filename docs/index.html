5 It Didn't Work Perfectly — We Fixed It

Every problem had a solution. This is normal — even experts iterate.

Problem 1: AI thinking out loud
Qwen3 wraps reasoning in <think>...</think> tags, cluttering the output.
Fix: Strip <think> blocks → clean output.
Problem 2: Inconsistent format
Sometimes "Score: 80/100", sometimes a paragraph.
Fix: Demand JSON → {"score": 80, "recommendation": "INVITE"}
Problem 3: Inconsistent eligibility checks
Without clear structure, AI answers varied by phrasing.
Fix: Inject FULL eligibility criteria into every prompt — no chunk splitting, no guessing.
