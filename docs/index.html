5 It Didn't Work Perfectly — We Fixed It

Every problem had a solution. This is normal — even experts iterate.


Problem 1: AI thinking out loud
Qwen3 wraps internal reasoning in <think>...</think> tags.
Before: <think>Let me analyze...</think> Score: 80
Fix: Added code to strip <think> blocks → clean output.
Problem 2: Inconsistent format
Sometimes "Score: 80/100", sometimes "80 points", sometimes a paragraph.
Fix: Demanded JSON output → {"score": 80, "recommendation": "INVITE"}
Problem 3: RAG missed answers
Asked AnythingLLM: "Minimum employees for Export program?"
Answer: "Not found" — even though it's in the document!
Root cause: RAG splits docs into chunks. The answer chunk wasn't retrieved.
Fix: Built a direct pipeline injecting FULL criteria into each prompt → "Minimum 5 employees"

6 Good Prompts = Good Results

The RCTF Formula: Role · Context · Task · Format


❌ Bad Prompt
"هل هذا الطلب جيد؟"

→ Vague, general answer. Useless for evaluation.

✅ Good Prompt (RCTF)
الدور: أنت مسؤول تقييم في JEDCO تطبّق معايير برنامج تطوير بصرامة.
السياق: رخصة المهن تنتهي 31/12/2025، توقيع العقد أيلول 2025.
المهمة: هل يستوفي الطلب شرط صلاحية الرخصة طوال فترة التنفيذ؟
الصيغة: كلمة واحدة أولاً ثم التوضيح.

→ "غير مستوفي" — الرخصة تنتهي في الشهر الرابع من التنفيذ.


Same AI. Same document. The quality of your question determines the quality of the answer.
